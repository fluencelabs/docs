# Build with AI

> Connect AI clients and agents to Fluence, and use the Fluence docs with LLMs.

To let Claude Code, Cursor, Codex, or another MCP client manage CPU virtual machines, GPU instances, and cloud agents with a Fluence API key, start with [Connect an AI client through MCP](https://fluence.dev/docs/build_with_ai/mcp.md). The [MCP server reference](https://fluence.dev/docs/build_with_ai/mcp_reference.md) lists the tools, permissions, limits, and errors. An agent that pays with its own wallet can fund an account over HTTP with x402 (USDC on Base) or MPP (USDC.e on Tempo). See [Pay with x402 or MPP](https://fluence.dev/docs/build/api/x402.md).
