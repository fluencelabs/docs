# Connect Servers

> Guides for data center operators who connect bare metal servers to Fluence Cloud as compute providers. Providers run Talos Linux and Kubernetes on their servers, and Fluence customers' virtual machines run in those clusters.

Providers must operate Tier 3 or Tier 4 data centers and pass a KYB review before they join. Providers manage their servers in the [Fluence Provider Application](https://providers.fluence.network). Start with the [Overview](https://fluence.dev/docs/connect_servers/overview.md) for the data center, hardware, and network requirements. Then follow the guides in order: log in, add servers, create a Kubernetes cluster, and add an IP subnet.
